# Smart Cafeteria Menu & Queue Management System

A full-stack web application developed as a group project for **CSC574 – Dynamic Web Application Development** at **Universiti Teknologi MARA (UiTM)**.

The system is designed to improve cafeteria operations by supporting online food ordering, pickup queue management, and centralized order and menu administration.

## Overview

Students often have limited time between classes, while cafeterias experience long queues during busy periods. This project explores a web-based approach to simplifying food orders and improving visibility into order status and pickup queues.

## Key Features

- **Customer:** Account registration and login, menu browsing, shopping cart, order tracking, and reviews.
- **Cafeteria staff:** Dashboard, menu item management, order management, inventory/menu stock, and pickup queue.
- **Administrator:** Administrative dashboard and user/operational management interfaces.
- **Responsive interface:** Layouts designed for use across screen sizes.

## System Modules

The application provides interfaces for three user roles:

1. **Customers** — browse food items, place orders, monitor orders, and leave feedback.
2. **Cafeteria staff** — manage menus, stock, incoming orders, and pickup queues.
3. **Administrators** — access administrative management functions.

## Getting Started

This is a PHP and MySQL application. The exact installation and database import steps depend on the repository's file structure and configuration.

1. Clone the repository:
   ```bash
   git clone https://github.com/ashrafhamim18/Cafeteria-System.git
   ```
2. Set up a local PHP/MySQL environment (for example, XAMPP).
3. Configure the application's database connection for your local environment.
4. Import the project's SQL schema or database export, **if included**.
5. Start the local web server and open the application's entry point in your browser.

> **Note:** Check the actual project files for the correct database name, entry point, and setup steps before treating this section as a complete installation guide. Never commit real passwords or other secrets.
